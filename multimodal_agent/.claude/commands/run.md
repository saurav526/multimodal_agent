---
description: Set up the environment and launch the Streamlit app
---

From the `multimodal_agent/` project folder:

1. Create `.venv` if it does not exist and install `requirements.txt`.
2. Check that `.env` exists with `GROQ_API_KEY`. If missing, create `.env.example` and tell me to fill in `.env`. Do not read the key's value.
3. Run `streamlit run app.py` and report the local URL.
